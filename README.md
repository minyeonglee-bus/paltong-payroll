# Paltong Payroll (급여 앱)

Paltong Restaurant 근로계약서 기준 급여 앱. 보름치 시프트 표를 넣으면 기본급·초과·야간·휴일 할증·SIL·지각 공제·가불·현금 부족분까지 자동 계산하고, 급여명세서를 뽑아요.

- **Supabase**: 데이터베이스, 로그인
- **Vercel**: 앱 호스팅 (정적 파일, 서버 함수 없음)

## 폴더

```
index.html, app.js, data.js, style.css   앱 화면
config.js                                 Supabase URL / anon key (공개값)
payroll-calc.js                           급여 계산식 (test/payroll.test.js 로 검증)
supabase/schema.sql                       테이블 · 권한(RLS) · admin 계정
```

## 설치 (처음 한 번)

1. **Supabase** → 새 프로젝트 → SQL Editor → `supabase/schema.sql` 전체 실행
   - 관리자 계정 `admin` / `paltong1234` 가 만들어져요. 로그인 후 메뉴(⋯) → 비밀번호 변경.
2. Supabase → Project Settings → API 에서 **Project URL** 과 **anon public key** 를 복사해 `config.js` 에 붙여넣기
3. **GitHub** 에 올리고 **Vercel** → Add New Project → 이 저장소 Import → Framework: Other → Deploy
4. 폰에서 Vercel 주소 열고 "홈 화면에 추가"

## 사용법

| 탭 | 하는 일 |
|---|---|
| 급여 계산 | 직원 · 월 · 기간(1~15 / 16~말일) 선택 → 날짜별 시프트(08-18 / 18-04 / 08-20 / 20-04 / 22-08 / 20-08)와 종류(평일·휴무일·공휴일·SIL·휴무) 선택 → 자동 계산 → 저장 → 지급 완료로 기록 → 급여명세서 인쇄 |
| 직원 | 이름, 직위(웨이터/주방/라이더), 일급, 고용 형태, 입사일 |
| 가불·부족분 | 가불은 날짜 기준으로 15일/30일 급여에 자동 차감 (1~15일 → 15일, 16일~ → 30일). 현금 부족분은 **웨이터만**, "조사 완료·본인 책임 확인" 체크된 것만 차감 |
| 급여 내역 | 기간별 저장된 급여, 합계 |
| 설정 | 기본 일급(최저임금 ₱718), 식사 휴게, 법정 공제 기본값, 언어 |

## 계산 규칙 (계약서 + DOLE)

- 시급 = 일급 ÷ 8. 시프트 시간 − 식사 휴게(기본 1h) = 근무시간, 8시간 초과분은 초과근무
- 초과 125% · 휴무일/특별공휴일 130% (초과 169%) · 정규공휴일 200% (쉬어도 100%, 초과 260%) · 야간(22~06시) +10%
- SIL · 개근 유급휴가: 일급 100%
- 지각·조퇴: 실제 미근무 분 × (일급 ÷ 480)
- 법정 공제(선택): SSS 5% · PhilHealth 2.5% · Pag-IBIG 2%(최대 ₱200), 월 기본급 = 일급 × 313 ÷ 12. 요율은 해마다 확인하세요
- 지급 완료된 급여는 관리자만 수정·삭제 가능 (DB 규칙)

`npm test` 로 계산식을 검증할 수 있어요.

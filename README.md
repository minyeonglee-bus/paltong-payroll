# Paltong Payroll (급여 앱)

Paltong Restaurant 급여 앱. 직원마다 **계산 방식**을 골라요 (직원 탭): **718 계약서** (라이더 · Jonel · Genifer · Albert · Lorence — 8h, OT 125%, 야간 +10%) 또는 **기존 종이 방식** (Archie · Jonathan · Erika · Lilian — 9월까지 쓰던 일급 그대로, 근무일 × 일급, 카드 OT × 일급÷10, 지각 + 벌금). 보름치를 넣으면 가불·현금 부족분·보너스까지 자동 계산하고, 급여명세서(58mm 영수증 / A4)를 뽑아요.

| 급여 형태 | 누구 | 기간 | 계산 |
|---|---|---|---|
| **718 계약서** (일급 ₱718) | 라이더 · Genifer · Albert · Lorence | 1~15 / 16~말일 | 시프트 × 시급(일급÷8) + 8h 초과분 125% (30분 단위 내림) + 야간(22~06) +10% + 휴무일 130% · 특별공휴일 130% · 정규공휴일 200%(쉬어도 100%) + 유급휴가 1일 − 지각 실제 분(일급÷480) − 가불. 라이더는 + 정비비 ₱100/근무일 (기본급 아님, 13월급 제외) |
| **기존 종이 방식** (기록용) | 9월까지의 과거 급여 | 1~15 / 16~말일 | 근무일 × 일급 (시프트 길이 무관, 반일 ½) + 카드 OT 시간 × (일급 ÷ 10) + 특별공휴일 +30% · 정규공휴일 +1일 + 유급휴가 1일 − 지각(분 × 일급÷600) − 같은 금액 벌금 − 가불(CA). 웨이터는 확인된 현금 부족분 공제 |
| **월급** ₱30,000 (계약서) | 주방 Jonel | 1~15 / 16~말일 | 반월 ₱15,000 고정. 초과근무는 월급에 포함(별도 없음). 야간·공휴일 가산은 별도. 결근·지각은 일할(월급 × 12 ÷ 313) 공제 |

- **Supabase**: 캐시북(MONEY TRACKER) 프로젝트에 `pr_` 테이블로 추가 · 로그인은 캐시북 계정 공용
- **Vercel**: 앱 호스팅 (정적 파일, 서버 함수 없음)

## 폴더

```
index.html, app.js, data.js, style.css   앱 화면
config.js                                 Supabase URL / anon key (공개값)
payroll-calc.js                           급여 계산식 (test/payroll.test.js 로 검증)
supabase/schema.sql                       테이블 · 권한(RLS) · admin 계정
```

## 설치 (처음 한 번)

1. **Supabase (MONEY TRACKER = 캐시북 프로젝트)** → SQL Editor → `supabase/schema.sql` 전체 실행 (여러 번 실행해도 안전 · 기존 테이블에 새 칸만 추가돼요)
   - 캐시북과 같은 프로젝트를 쓰지만 테이블 이름이 `pr_`로 시작해서 캐시북 데이터는 건드리지 않아요.
   - 로그인은 **캐시북 admin(관리자) 계정 그대로**. 급여 데이터는 관리자만 볼 수 있어요 (직원 계정은 로그인해도 안 보임).
2. `config.js` 에는 이미 캐시북과 같은 URL/anon key가 들어 있어요.
3. **GitHub** 에 올리고 **Vercel** → Add New Project → 이 저장소 Import → Framework: Other → Deploy
4. 폰에서 Vercel 주소 열고 "홈 화면에 추가"

## 사용법

|---|---|
| 급여 계산 | 직원 · 월 · 기간(1~15 / 16~말일) 선택 → "캐시북 스케줄 불러오기" 또는 "전체 채우기" 후 쉬는 날은 날짜를 눌러 휴무 (휴무 요일 고정 없음, 주말 = 금·토) → 날짜별 시프트(기록용)와 종류(근무·반일·공휴일·유급휴가·휴무), **OT 시간**(카드에 적은 +1, +2…) 입력 → 지각 분 입력 → 자동 계산 → 저장 → 지급 완료로 기록 → 급여명세서 인쇄 |
| 직원 | 이름, 직원 번호, 직위(웨이터/주방/라이더), 급여 형태(일급/월급)와 금액, **계산 방식(718 계약서 / 기존 종이 방식)**, 고용 형태, 입사일 |
| 가불·부족분·보너스 | **🏆 최고매출일 보너스 계산**: 보름 중 캐시북 매출 최고일 × 2% ÷ 그날 출퇴근 기록이 있는 직원 수 → 체크 확인 후 보너스로 저장 (계약서 6조). 가불은 날짜 기준으로 15일/30일 급여에 자동 차감 (1~15일 → 15일, 16일~ → 30일). 현금 부족분은 **웨이터만**, "본인 책임 확인" + "서면 동의" 둘 다 체크된 것만 차감. **보너스(+)** 는 주간 최고매출일 보너스(매출 2% ÷ 근무 대상자 수)나 주방 신메뉴 인센티브를 날짜별로 넣으면 그 기간 급여에 더해져요 |
| 급여 내역 | 기간별 저장된 급여, 합계 |
| 13월급 | 연도별로 직원마다 앱에 저장된 급여의 기본급(초과·공휴일 가산·정비비·보너스 제외)을 합산 ÷ 12 (1년 이상은 한 달 평균). 앱 쓰기 전 올해 기본급은 직원 탭에 손으로 입력. 연말 예상치 참고 표시. "지급 기록" 누르면 지급 완료로 저장되고 직원 본인 화면에도 보여요 |
| 설정 | 기본 일급(₱718), 식사 휴게, 라이더 정비비, 주방 월급 기본값, 기존 방식용 하루 기준 시간(OT 시급 = 일급 ÷ 10)·지각 벌금 on/off, 법정 공제 기본값, 언어, 계산 방식 요약 |

## 캐시북 현금 부족 연동 (웨이터)

- 캐시북에서 중간마감·마감 때 **센 현금이 장부보다 모자라면** 가불·부족분 탭 맨 위 **"캐시북 현금 부족 (확인 필요)"** 에 자동으로 들어와요 (날짜, 금액, 센 사람, 사유, 그날 근무자)
- **자동으로 빠지지 않아요.** 조사 → 책임 웨이터 한 명 지정 → 가불·부족분에서 **본인 책임 확인 + 서면 동의** 둘 다 체크해야 급여에서 공제
- 돈을 찾았거나 장부 실수면 **해결됨 — 공제 안 함**
- 근무자 전원에게 나눠서 빼는 건 안 돼요 (DOLE · 계약서)

## 직원 본인 출퇴근 (앱이 근태 기준)

- 직원이 번호 + PIN으로 로그인하면 맨 위에 **▶ 출근 / ■ 퇴근** 버튼. 누른 시각이 서버 시간으로 저장돼요 (같은 버튼 2분 안 중복은 무시).
- 관리자 급여 계산 탭에서 **"앱 출퇴근 불러오기"** → 날짜별 첫 출근~마지막 퇴근이 타임카드 시프트로 들어와요. 밤 근무(퇴근이 다음날 새벽)는 출근한 날짜로 잡아요. 출근/퇴근 한쪽이 없는 날은 비워두고 알려줘요.
- 같은 탭 아래 **"앱 출퇴근 기록 (이 기간)"** 에서 관리자가 잘못 누른 기록 삭제·빠진 기록 추가 가능.
- SQL: `supabase/pr_punches.sql` (테이블 `pr_punches`, RPC `pr_punch`, `pr_emp_view`에 최근 45일 기록 포함)

## 직원 본인 보기 (번호 + PIN)

- 로그인 화면에서 **직원** 선택 → 직원 번호(예: 00001) + PIN
- 처음 PIN은 **0000** → 로그인하면 본인이 4~6자리 PIN으로 다시 등록 (0000 안 됨)
- 5번 틀리면 10분 잠김 · PIN을 잊으면 관리자가 직원 탭 → 이름 → **PIN 초기화 (0000)**
- 직원은 **본인 것만** 봐요: 지급 완료된 급여명세서, 가불·부족분, 근무(시프트) 기록. 수정은 못 해요
- **내 급여 계산기 (예상)**: 직원이 직접 시프트를 넣어 예상 급여를 볼 수 있어요. 일급·급여 형태는 직원 정보에서 자동. 법정 공제(SSS·PhilHealth·Pag-IBIG) 체크만 가능하고 가불·보너스·부족분·인센티브는 없어요. 저장 안 됨 — 실제 금액은 지급된 급여명세서 기준

## 타임카드 입력

**718 계약서 직원**: 시프트(출근·퇴근)를 넣으면 휴게 1시간 빼고 8시간까지 기본, 넘는 시간은 30분 단위 내림으로 OT 125%, 야간(22~06시) +10%가 자동. 지각은 실제 분만 공제 (벌금 없음).

**기존 종이 방식 직원**:
- 급여는 **하루 단위**예요: 근무한 날은 시프트 길이와 상관없이 일급 1일. 시프트 칸은 기록용(캐시북 스케줄 불러오기 가능).
- 하루 = **10시간 시프트**(08~18). 시프트가 10시간을 넘으면 넘는 만큼(30분 단위) 자동으로 OT (08~19 → +1h). 카드에 적힌 숫자를 날짜별 OT 칸에 직접 넣으면 그 값을 써요 (비우면 다시 자동). OT 1시간 = 일급 ÷ 10 (790 → 79). 125% 배율·야간 가산 없음.
- **지각·조퇴**는 분 합계로 넣으면 일급 ÷ 10 ÷ 60 으로 공제하고(690 → 30분 34.5), 같은 금액이 **벌금**으로 한 번 더 빠져요 (설정에서 끌 수 있어요).
- 특별공휴일 근무 +30% (658 → +197), 정규공휴일(1/1, 5/1 등) +1일 — 쉬어도 "정규공휴일 쉼"으로 1일, 유급휴가 1일, 반일 ½.

공통: 실수령은 1페소 단위 **올림**. 배달비는 당일 지급이라 급여에 안 들어가고, 라이더 정비비 ₱100/근무일만 들어가요.
- 지급 완료된 급여는 지급 당시 계산 결과를 그대로 보여줘요 (계산식이 바뀌어도 과거 급여는 안 변함).

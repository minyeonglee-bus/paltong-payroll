# Paltong Payroll (급여 앱)

Paltong Restaurant 근로계약서(웨이터 · 주방 일급/월급 · 라이더) 기준 급여 앱. 보름치 근무표를 넣으면 기본급·초과·야간·휴일 할증·SIL·지각·결근 공제·가불·현금 부족분·보너스까지 자동 계산하고, 급여명세서를 뽑아요.

| 급여 형태 | 누구 | 기간 | 계산 |
|---|---|---|---|
| **일급** ₱718 | 웨이터 · 주방 · 라이더 | 1~15 / 16~말일 | 시프트 × 시급, 초과 125%, 야간 +10%, 휴일 할증, SIL 100%, 지각 분 공제. 라이더는 + 정비비 ₱100/근무일 (기본급 아님, 13월급 제외). 웨이터는 확인된 현금 부족분 공제 |
| **월급** ₱30,000 | 주방 (OT 포함 계약) | 1~15 / 16~말일 | 반월 ₱15,000 고정. 초과근무는 월급에 포함(별도 없음). 야간·휴일·휴무일 할증은 별도 지급. 결근·지각은 일할(월급 × 12 ÷ 313) 공제 |

- **Supabase**: 캐시북(MONEY TRACKER) 프로젝트에 `pr_` 테이블로 추가 · 로그인은 캐시북 계정 공용
- **Vercel**: 앱 호스팅 (정적 파일, 서버 함수 없음)

## 폴더

```
index.html, app.js, data.js, style.css   앱 화면
config.js                                 Supabase URL / anon key (공개값)
payroll-calc.js                           급여 계산식 (test/payroll.test.js 로 검증)
supabase/schema.sql                       테이블 · 권한(RLS) · admin 계정
```

## 설치 (처음 한 번)

1. **Supabase (MONEY TRACKER = 캐시북 프로젝트)** → SQL Editor → `supabase/schema.sql` 전체 실행 (여러 번 실행해도 안전 · 기존 테이블에 새 칸만 추가돼요)
   - 캐시북과 같은 프로젝트를 쓰지만 테이블 이름이 `pr_`로 시작해서 캐시북 데이터는 건드리지 않아요.
   - 로그인은 **캐시북 admin(관리자) 계정 그대로**. 급여 데이터는 관리자만 볼 수 있어요 (직원 계정은 로그인해도 안 보임).
2. `config.js` 에는 이미 캐시북과 같은 URL/anon key가 들어 있어요.
3. **GitHub** 에 올리고 **Vercel** → Add New Project → 이 저장소 Import → Framework: Other → Deploy
4. 폰에서 Vercel 주소 열고 "홈 화면에 추가"

## 사용법

| 탭 | 하는 일 |
|---|---|
| 급여 계산 | 직원 · 월 · 기간(1~15 / 16~말일) 선택 → "캐시북 스케줄 불러오기" 또는 "전체 채우기" 후 쉬는 날은 날짜를 눌러 휴무 (휴무 요일 고정 없음, 주말 = 금·토) → 날짜별 시프트(08-18 / 18-04 / 08-20 / 20-04 / 22-08 / 20-08)와 종류(평일·휴무일·공휴일·SIL·휴무) 선택 → 자동 계산 → 저장 → 지급 완료로 기록 → 급여명세서 인쇄 |
| 직원 | 이름, 직원 번호, 직위(웨이터/주방/라이더), 급여 형태(일급/월급)와 금액, 고용 형태, 입사일 |
| 가불·부족분·보너스 | 가불은 날짜 기준으로 15일/30일 급여에 자동 차감 (1~15일 → 15일, 16일~ → 30일). 현금 부족분은 **웨이터만**, "본인 책임 확인" + "서면 동의" 둘 다 체크된 것만 차감. **보너스(+)** 는 주간 최고매출일 보너스(매출 2% ÷ 근무 대상자 수)나 주방 신메뉴 인센티브를 날짜별로 넣으면 그 기간 급여에 더해져요 |
| 급여 내역 | 기간별 저장된 급여, 합계 |
| 설정 | 기본 일급(최저임금 ₱718), 식사 휴게, 라이더 정비비, 주방 월급 기본값, 법정 공제 기본값, 언어, 계약서 4종 요약 |

## 캐시북 현금 부족 연동 (웨이터)

- 캐시북에서 중간마감·마감 때 **센 현금이 장부보다 모자라면** 가불·부족분 탭 맨 위 **"캐시북 현금 부족 (확인 필요)"** 에 자동으로 들어와요 (날짜, 금액, 센 사람, 사유, 그날 근무자)
- **자동으로 빠지지 않아요.** 조사 → 책임 웨이터 한 명 지정 → 가불·부족분에서 **본인 책임 확인 + 서면 동의** 둘 다 체크해야 급여에서 공제
- 돈을 찾았거나 장부 실수면 **해결됨 — 공제 안 함**
- 근무자 전원에게 나눠서 빼는 건 안 돼요 (DOLE · 계약서)

## 직원 본인 보기 (번호 + PIN)

- 로그인 화면에서 **직원** 선택 → 직원 번호(예: 00001) + PIN
- 처음 PIN은 **0000** → 로그인하면 본인이 4~6자리 PIN으로 다시 등록 (0000 안 됨)
- 5번 틀리면 10분 잠김 · PIN을 잊으면 관리자가 직원 탭 → 이름 → **PIN 초기화 (0000)**
- 직원은 **본인 것만** 봐요: 지급 완료된 급여명세서, 가불·부족분, 근무(시프트) 기록. 수정은 못 해요
- **내 급여 계산기 (예상)**: 직원이 직접 시프트를 넣어 예상 급여를 볼 수 있어요. 일급·급여 형태는 직원 정보에서 자동. 법정 공제(SSS·PhilHealth·Pag-IBIG) 체크만 가능하고 가불·보너스·부족분·인센티브는 없어요. 저장 안 됨 — 실제 금액은 지급된 급여명세서 기준

## 계산 규칙 (계약서 + DOLE)

- 시급 = 일급 ÷ 8. 시프트 시간 − 식사 휴게(기본 1h) = 근무시간, 8시간 초과분은 초과근무
- 초과 125% · 휴무일/특별공휴일 130% (초과 169%) · 정규공휴일 200% (쉬어도 100%, 초과 260%) · 야간(22~06시) +10%
- SIL · 개근 유급휴가: 일급 100% (월급제는 월급에 이미 포함 → 추가 지급·공제 없음)
- 월급제(₱30,000): 반월 기본급 15,000 고정 · 초과근무 미지급(포함) · 결근 1일 = 30,000 × 12 ÷ 313 = ₱1,150.16 공제
- 13월급 산정용 기본급은 계산 내역 아래에 따로 표시돼요 (수당·초과·할증·보너스 제외)
- 지각·조퇴: 실제 미근무 분 × (일급 ÷ 480)
- 법정 공제(선택): SSS 5% · PhilHealth 2.5% · Pag-IBIG 2%(최대 ₱200), 월 기본급 = 일급 × 313 ÷ 12. 요율은 해마다 확인하세요
- 지급 완료된 급여는 관리자만 수정·삭제 가능 (DB 규칙)

`npm test` 로 계산식을 검증할 수 있어요.
